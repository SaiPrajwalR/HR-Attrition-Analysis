# HR Employee Attrition Analysis Dashboard

## Project Overview
This project analyzes employee attrition to identify workforce trends, understand factors associated with employee turnover, and support data-driven HR decisions.

The project uses SQL for data analysis and database management, Microsoft Excel for interactive dashboard reporting, and Power BI for advanced visualization and HR analytics.

## Tools & Technologies
- **SQL / MySQL** — Data querying, joins, aggregations, and analysis
- **Microsoft Excel** — Dashboard development, PivotTables, charts, and KPI reporting
- **Microsoft Power BI** — Interactive dashboards, data modeling, and DAX measures

## Project Objectives
- Analyze overall employee attrition.
- Compare attrition across departments.
- Examine the relationship between overtime and attrition.
- Analyze compensation and employee satisfaction.
- Identify workforce trends that can inform HR retention strategies.

## Key Findings
- Total employees analyzed: 1,470
- Employees who left: 269
- Employees who stayed: 1,201
- Overall attrition rate: 18.3%
- Attrition rate among employees working overtime: 25.7%
- Attrition rate among employees not working overtime: 15.4%

## Project Files
- SQL database and analysis scripts
- Excel HR attrition dashboard
- Power BI HR attrition dashboard

## Recommendations
- Investigate the relationship between overtime and employee turnover.
- Review attrition patterns across departments.
- Examine compensation and employee satisfaction to identify potential retention opportunities.

## Disclaimer
This project is intended for educational and portfolio purposes. Findings show associations in the analyzed dataset and do not establish causation.
